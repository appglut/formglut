== Description ==

FormGlut is a lightweight form builder plugin for WordPress with a modern drag-and-drop editor. Build forms, manage entries, and protect against spam — all from a clean, intuitive admin interface.

**Features**

* Drag-and-drop form editor with live preview
* 17 field types — text, email, textarea, number, select, radio, checkbox, date, file, hidden, URL, phone, name, address, HTML, heading, divider
* Customizable field styling — colors, padding, border radius, label placement, field width
* Customizable submit button — text, size, colors, alignment
* Entry management — read/unread status, starring, filtering, and search
* Form status control — active, draft, or closed
* Email notifications with customizable sender and subject
* reCAPTCHA v3 spam protection
* Honeypot spam protection
* Form analytics — views, submissions, and conversion rates
* Device preview — desktop, tablet, and mobile
* Responsive frontend forms
* Shortcode powered — embed any form with `[formglut id="X"]`
* AJAX form submission — no page reloads

== Installation ==

1. Upload the `formglut` folder to `/wp-content/plugins/`.
2. Activate the plugin through the Plugins menu in WordPress.
3. Navigate to **FormGlut** in the admin menu to start building forms.

== Frequently Asked Questions ==

= How do I add a form to a page? =

Use the shortcode `[formglut id="X"]` where X is your form ID.

= Does FormGlut work with any theme? =

Yes, FormGlut is designed to work with any properly coded WordPress theme.

= Will FormGlut slow down my website? =

No. FormGlut only loads its scripts and styles on pages that contain a FormGlut form.
