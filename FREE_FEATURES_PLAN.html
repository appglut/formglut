New sections the free plugin needs
  • Editor › Add Fields: a Payment category (Payment item, Custom amount, Credit card) and Layout fields for steps.
  • Form Settings: two new tabs: Multi-step (progress style, button labels) and Integrations (webhook, Mailchimp, HubSpot, Slack per form).
  • Global Settings: three new sections: Payments (Stripe keys), Integrations (API keys and webhook URLs) and Privacy (WordPress export / erase, IP handling).
  • Entries: an Export button, a Notes and Resend panel on the single entry, and a Print action.
  • All Forms: Import / Export and Add New › Templates.

How this was produced
  • The list is every row decided Free in the Free vs Pro decisions report, which merges the current Pro page, the competitor gap analysis and the Pro plan report and checks which other plugins give each feature away.
  • “Already built” was checked in the FormGlut code: everything under per-form settings (confirmation, notifications, restrictions, spam, layout) and the field options that already exist.
  • Phase 1 = unblocks other work or is a basic expectation (uploads, steps, CSV export, import / export, webhook, Gutenberg block). Phase 2 = common polish. Phase 3 = nice to have. Effort (S / M / L) is an estimate for this codebase.
