# MetForm Plugin v4.1.4 — Complete Feature List

> Plugin URI: https://wpmet.com/plugin/metform/
> Description: Elementor-based drag-and-drop WordPress form builder
> Last Updated: 2026-05-03

---

## FREE Features

### Core Form Builder

- Drag-and-drop Elementor-based form builder
- Real-time form preview
- Multi-column layout support
- AJAX form submission (no page refresh)
- Shortcode support (embed forms anywhere)
- Gutenberg block support
- Translation ready / multilingual support

### Form Submission & Entry Management

- Save all form entries in admin panel
- View individual entries
- Export entries as CSV
- Delete entries (with option to delete associated uploaded files)
- Custom post type for entries
- Hide form after submission
- Limit total entries per form
- Redirect after successful submission
- Editable success message
- Required field validation with error messages
- Required login to submit forms
- Capture user browser data (browser, visited URL, page title, visit time, visit count, user profile)
