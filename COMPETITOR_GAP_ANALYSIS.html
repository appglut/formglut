Suggested build order

Grouped so that each step unlocks the next. Priority in the tables is based on how many of the 11 competitors ship the item.

Multi-step formsPage break field, step progress bar, next/back, and save & resume. Every competitor ships steps (11/11); FormGlut only lists “Form Step” in the Pro registry.
File upload in the free pluginAll 11 competitors include uploads. Move it (with allowed types, max size, multiple files) into the free builder and attach files to emails.
Per-form Settings tabToday all settings are global. Add a form-level tab: notifications, confirmations, restrictions, styling. This unlocks most items below.
Notifications overhaulMultiple notifications, auto-responder, Reply-To / CC / BCC, conditional routing, smart tags and an HTML template.
Confirmations & redirectsPer-form success message, redirect to page/URL, conditional confirmations (the frontend already reads a redirect attribute; there is no setting).
Entries power toolsCSV export, edit entry, notes, resend notification, richer filters and an activity log.
Integrations: webhooks firstWebhooks unlock Zapier / Make / n8n for everything else; then Mailchimp, Google Sheets, Slack.
PaymentsStripe + PayPal with product, quantity, total and coupon fields (all in the Pro registry, none built).
Advanced fieldsCalculation, Repeater, Signature, Rating / NPS / Likert, Image choices, Toggle, Rich text: decide which ship free vs Pro.
Restrictions & spamScheduling, entry limits, login-required, per-IP limits; Akismet, keyword filter, rate limit, min-time, automatic spam log.
Where forms liveGutenberg block, Elementor widget, REST API, import / export, and a template library.
DesignGlobal form styler with presets, custom CSS per form, styled date picker.

How this was produced
  • Each of the 123 items was searched for in every competitor's PHP / JS / JSON source (vendor, node_modules, tests and translations excluded) using specific field, class and setting names.
  • FormGlut's own status was checked directly in the FormGlut and FormGlut Pro code, not by keyword.
  • These are free builds: some competitor features are only upsell stubs for their paid version, and block-based plugins (Gutena, Gutenverse) implement less. A code match proves the feature exists in the code, not that it works in the free tier. Verify an item in the competitor's UI before copying it.
  • Priority: High = shipped by 8+ of 11, Medium = 5–7, Low = 4 or fewer.
